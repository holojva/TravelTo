# 🌍 TravelTo — когда карта становится живой

**TravelTo** — это не просто приложение для путешествий. Это наша попытка собрать всё, чего нам самим не хватало в современных картах: удобство, честность, доступность и живой человеческий вклад.

## 🧠 Что это?

TravelTo — приложение, где люди сами делятся полезными точками, маршрутами и отзывами. Это живая карта, на которой каждый может оставить что-то важное — и помочь другим найти уникальные места, не попавшие в рекламные брошюры.

## 📱 Что умеет TravelTo

- Добавлять точки — с описанием, оценкой и категорией
- Оставлять отзывы — простая и удобная система комментариев
- Сохранять в избранное — способ найти точку в любой момент
- Использовать поиск — чтобы находить только нужное
- Получать только проверенные данные — всё проходит модерацию через Telegram-бота

## 🚧 В разработке

- Личные карты и маршруты
- Поддержка маломобильных пользователей (пандусы, Брайль, лифты)
- “КриминалуНет” — безопасные маршруты и районы
- “НадоОтойти” - Поиск туалетов рядом 
- “Место встречи” — оптимальные точки пересечения

## 🛠️ Технологии

- Android (Java, MVVM, WebView)
- Backend на Flask (Python), SQLite
- Передача данных через JSON, XML, HTML (GET/POST)
- SharedPreferences (локальное хранилище)
- Telegram Bot на pyTelegramBotAPI
- Многопоточность, DocumentBuilder, парсинг HTML
